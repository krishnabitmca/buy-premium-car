# Premium Car Deal Radar — UX / Product Plan

## Product job
Help a buyer answer: (1) which cars deserve attention, (2) why a car surfaced, and (3) what must be verified before spending time or money.

## UX principles
- Photo-first discovery: use the actual listing photography exposed by the source page.
- Explain the signal: show ask, comparable median, market gap, mileage and ownership without opening a table row.
- Separate measured evidence from judgement: market gap is a comparison; verification notes are explicit missing/conflicting facts.
- Keep dense technical detail behind "Inspect evidence".
- Never imply physical stock from page reachability.
- Keep conflicting data visible as a verification problem.

## Information architecture
Hero -> KPI strip -> sticky filters -> photo-first cards -> evidence modal -> new-source panel.

## P0 delivered
- Light premium automotive visual system instead of the black dashboard.
- Photo-first cards with lazy-loaded listing images and gallery navigation.
- Evidence modal with pricing, dates, ownership, certification and verification notes.
- Persistent filters and intuitive "Radar priority" sorting.
- Dashboard now keeps all current filtered inventory visible even when nothing changed in price.

## P1
Bangalore landed-cost estimate, price-history sparkline, watchlist, "new today"/"price dropped" events, physical stock confirmation.

## P2
Side-by-side compare, VIN/service-document capture, alerts and a user buying profile.
