# Critical Customer Journeys

## J-001 First-time search

Open website -> wait for catalog -> select brand -> select model or All Models -> choose condition -> set budget -> Search -> inspect results.

## J-002 Premium buyer

BMW/Audi/Mercedes-Benz -> Used -> ₹30–40L -> Bengaluru destination -> search India-wide -> inspect multiple marketplace sources.

## J-003 Demo buyer

Audi -> Demonstrator -> search -> verify demonstrator source coverage.

## J-004 Broad brand search

BMW -> All Models -> Used -> no price restriction -> verify results are not silently limited to two sources or one model.

## J-005 Refinement

Search -> apply fuel -> apply age -> apply city -> sort -> clear all -> verify complete reset.

## J-006 Failure recovery

Search while one marketplace fails -> verify other sources remain usable -> inspect source status -> retry after recovery.

## J-007 Zero results

Choose an intentionally restrictive combination -> verify a clear zero-result state and ability to broaden the search.

## J-008 Mobile/responsive

Repeat the critical catalog and search flow at desktop, tablet, and mobile widths.
